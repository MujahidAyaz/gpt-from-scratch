# GPT From Scratch

A small GPT-style decoder-only Transformer implemented from scratch using PyTorch.

## Goal

Build and understand the major components of a GPT-style language model:

- Tokenization
- Token embeddings
- Positional information
- Self-attention
- Causal masking
- Multi-head attention
- Feed-forward networks
- Residual connections
- Normalization
- Transformer blocks
- Next-token prediction
- Training
- Text generation

## Tech Stack

- Python
- PyTorch
- NumPy
